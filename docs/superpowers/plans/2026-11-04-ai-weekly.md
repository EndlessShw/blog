# AI Weekly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 实现用户已确认的独立 AI 周报栏目。

**Architecture:** 周报使用独立 Page 内容目录，专用 EJS 复用 Fluid 的外层布局与 Markdown 样式。Hexo 构建扩展校验内容、生成分页，并将周报加入现有文章搜索数据。

**Tech Stack:** 现有 Hexo 8、Fluid、EJS、moment、hexo-pagination、Node.js test，不新增依赖。

**Spec:** `docs/designs/2026-11-04-ai-weekly.md`

## Global Constraints

- 不生成真实周报，不添加生成服务、定时任务或自动发布。
- 不修改 node_modules，不混入普通文章模型；保留工作区已有改动。
- 每页 10 期，标题和正文可搜索，发布时间必须明确且含时区。

## Review Focus

- 零期报告也必须生成栏目入口。
- 第 11 期必须产生正确分页，跨页排序一致。
- 搜索结果指向单期详情，保留普通文章和 indexing 规则。
- 缓存重载及连续构建不能重复包装搜索生成器或丢失周报。
- 错误日期、缺少标题、错误路径/布局必须失败，不能回退文件时间。
